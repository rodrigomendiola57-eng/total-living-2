# Carpeta de contexto — Total Living

**Propósito:** Conservar el hilo de trabajo del proyecto para cuando una nueva conversación no tenga historial. El usuario puede adjuntar esta carpeta (`CONTEXTO_PROYECTO`) al chat y pedir: *“Lee este contexto y continúa desde donde íbamos”*.

## Cómo usarla (usuario)

1. Adjuntar la carpeta **CONTEXTO_PROYECTO** (o los `.md` que contiene) al mensaje.
2. Indicar la tarea concreta (por ejemplo: “sigue el Día 4 del plan”).
