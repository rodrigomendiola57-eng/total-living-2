# 📸 LOGO TOTAL LIVING

## Archivos Necesarios

Coloca aquí los siguientes archivos del logo:

1. **logo.svg** o **logo.png** - Logo completo con texto "TOTAL LIVING"
   - Tamaño recomendado: 200-250px de ancho
   - Fondo transparente

2. **logo-icon.svg** o **logo-icon.png** - Solo el icono (TL combinado)
   - Para usar en favicon y espacios pequeños
   - Tamaño: 64x64px o más

3. **favicon.ico** - Favicon del navegador
   - Tamaño: 32x32px o 64x64px

## Formato Preferido

**SVG es el mejor formato** porque:
- No se pixelea
- Escalable
- Tamaño pequeño
- Perfecto para web

Si solo tienes PNG:
- Resolución mínima: 2000x2000px
- Fondo transparente
- Alta calidad

## Nota

Una vez que coloques los archivos aquí, el sistema los detectará automáticamente.
